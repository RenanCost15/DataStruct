# Fundamentos de Python — Capítulo 1

Material simples para acompanhar o Capítulo 1, **Programação Básica em Python**.

- `examples/`: exemplos apresentados durante o capítulo;
- `projects/`: respostas dos dez projetos finais.

Todo o conteúdo foi conferido exclusivamente na edição original em inglês. Os exemplos
mantêm a estrutura apresentada pelo livro; somente mensagens e comentários foram
traduzidos para português. Cada arquivo começa com um comentário indicando a seção ou
a questão e a página correspondente do capítulo.

Não há bibliotecas externas, testes automatizados nem um executor geral. A ideia é abrir,
ler e executar um arquivo de cada vez, junto com a leitura do livro.

## Executar no Windows

No PowerShell, dentro da pasta do repositório, confira primeiro se o Python está disponível:

```powershell
py --version
```

Se o comando funcionar, execute um arquivo assim:

```powershell
py examples\ex01_numberguess.py
py projects\p01_sphere.py
```

Se `py` também não funcionar, instale o Python pelo site oficial ou pela Microsoft Store,
feche o PowerShell e abra uma nova janela antes de tentar novamente.
