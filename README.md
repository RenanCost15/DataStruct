# Fundamentals of Python: Data Structures — Capítulos 1 a 6 — PT-BR

O livro é a especificação fechada do repositório:

- `EXEMPLOS`: somente código, sessões ou algoritmos que o livro efetivamente apresenta.
- `EXERCICIOS`: exatamente os blocos `Exercises` dos capítulos, com resolução.
- `QUESTOES_REVISAO`: exatamente `Review Questions`, com resposta/justificativa.
- `PROJETOS`: exatamente `Projects`, com resolução; quando o livro pede diagrama, a resolução é um arquivo Markdown, não um programa artificial.
- `ATIVIDADES`: somente estudos de caso/atividades formalmente identificados no texto.

Os identificadores exigidos pelo livro (`ArrayBag`, `LinkedBag`, `__iter__`, etc.) são preservados para que o código continue correspondendo ao texto; comentários, explicações e mensagens são apresentados em PT-BR sempre que isso não altera a API solicitada.
